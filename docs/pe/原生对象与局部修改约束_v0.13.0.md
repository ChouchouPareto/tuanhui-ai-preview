# 原生对象与局部修改约束 v0.13.0

2026-09-16；需求 R02/R04/R06/R08/R09/R15。仅新增，不覆盖 v0.10.0/v0.10.1 等历史 PE。

本文件说明已落地的结构合同与后续模型接入边界，不冒充已经向模型发送的新 system prompt。当前 `resolve-edit` 是本地保守解析；不确定时返回候选。完整语义模型/父子 Agent 尚未接入这份合同。

## Input → Output

1. 新图：确认的输出类型/构图/文案 → 无字视觉底图 → 本地含字检查 → 可编辑文字节点 → 容量/碰撞/安全区检查 → 排字 → 保存原生场景及无字底层 → 导出母版和 4:3 切片。
2. 导入编辑：指定已成功单项任务 → 校验 `editable-scene.json` 和 `typography-base.png` 指纹 → 建画布及首个不可变版本。全案必须指定子作品任务，不猜第一项。旧图无结构时返回 `NO_EDITABLE_SOURCE`。
3. 对话改字：当前作品版本 + 消息 + 可选选中 ID/原文/角色/切片 → 约束交集 → 唯一对象且替换动作明确才生成 proposal；此步骤不改作品。
4. 应用：proposal + 相同基版本 + 幂等键 → 校验锁定/版本/几何/来源 → 局部排字 → 保存新版本和图片指纹。旧版不覆盖，其他对象不修改，无模型兜底。
5. 导出：明确版本 → 读取该版本冻结的 PNG、校验指纹 → 可选带/不带水印 → 最终 4:3 切片或 ZIP。预览默认 inline，下载需单独动作。

## 机器可读结构

字段由 `backend/app/canvas_schemas.py` 定义，未知字段、任意路径/URL、脚本、非有限坐标及重复对象 ID 均拒绝。以下为五连图主/副标题的结构示例，不是实际模板库审核成品：

```json
{
  "schema_version": "editable-scene-v1",
  "output_type": "five_panel",
  "width": 4000,
  "height": 600,
  "slice_count": 5,
  "background_color": "#173d35",
  "ai_generated": true,
  "nodes": [
    {"id": "text_headline", "kind": "text", "role": "headline", "text": "好好吃一餐", "box": [0.025, 0.10, 0.15, 0.25], "font_size": 60, "color": "#fff4dc"},
    {"id": "text_subheadline", "kind": "text", "role": "subheadline", "text": "今天来点热乎的", "box": [0.025, 0.42, 0.15, 0.16], "font_size": 32, "color": "#fff4dc"}
  ]
}
```

`box=[x,y,width,height]` 为相对母版的 0～1 坐标；不是无限画布视口坐标。对象 ID 稳定，role 区分主标题、副标题、店名、价格、正文、图片和装饰。实际排字字号/换行由渲染结果 `text_layout` 返回，不用模型猜字体像素。

## 已执行约束

- 五图 4000×600 / 三图 2400×600，单图 800×600；不把五张独立图拼成母版。
- 文字对象不得跨导出切缝。原模板文字区跨缝时，排字取该区与最大单片安全区的交集；保留全景视觉，不把每片强制做成独立场景。字太多放不下则拒绝，不截断事实。
- 两个可见文字框不重叠；Logo/套餐/代金券核心文字和核心图片在中央 1:1 内，装饰可延伸；AI 示例水印区域保留。
- 原图/门头/菜单不等于可渲染照片对象。图片层只能引用本项目已允许的素材，不能传外网地址或本机任意路径。
- 无原生对象不能说“无损修改成功”。当前视觉底层是合成平面，尚不承诺拆出盘子、食物等所有物体。
- 相同 key 相同修改只执行一次；同 key 不同请求冲突；并发基版本过期不能覆盖最新作品。
- 恢复是追加新版本；分支复制生成独立画布；保存时冻结实际 PNG，未来字体/代码变化不改历史像素。
- 导出无水印只是输出选项，不改变来源 `ai_generated`；失败不增加图像模型调用。

## 后续 Agent 必须遵守的工具边界

Agent 只能返回合法对象 ID、目标版本和允许的 operation，不得自行拼路径、伪造用户授权、解锁用户锁定对象或用整图重生代替局部编辑。服务端即使收到合法 JSON 仍须做校验。

“标题改一下”必须结合候选原文；“主标题改成 X”可定位主标题；选中副标题却写“改主标题”必须澄清；“不要改”“能不能改”不能直接应用；复合动作不得丢掉其中一项后声称全部完成。

父子工具网关、语义提案评测和 Figma 交互仍待后续开发。本地几何测试不能证明文案吸引力、美术质量或模型理解正确率。
