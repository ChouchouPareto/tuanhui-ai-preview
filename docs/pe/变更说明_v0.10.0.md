# PE与模板约束优化 v0.10.0

## 已生效的代码改动

1. 新建 generation_v3.md、copywriting_v1.md，并由 build_visual_prompt 实际读取，不只是文档备份。
2. 构图从原先五等分改为12种整图区域模板：文字区、1—3个主辅视觉区、可选装饰区。区域框不入画；不再要求每张切片有标题。
3. 新方案存储 layout_id、库版本、具体区域，调用前验证与登记模板一致。初版使用素材数量过滤和稳定规则选择，不冒充LLM自主选型；不增加付费调用。
4. 本地排版消费模板文字区与真实素材区，不再固定底部黑渐变、上下横线、左上红色店名块或重复文案。
5. 文案PE覆盖事实、吸引力、表达尺度和检查；程序提供风险词与容量初筛。当前候选文案仍是保守规则生成，不是独立文案模型；初筛不等于法律合规审查。
6. 门头单候选即使被模型填成店名，也必须通过置信度和可见文字证据检查。色彩、风格、Logo线索附图中区域和依据，作为候选保存；不能承诺OCR永不出错。
7. 现有素材分析流程增加店内环境资料识别，并保存OCR记录。已确认项目品牌色可作为生成资料传递；低置信候选、Logo线索不会自动变成可用Logo。门头原图始终不用于成品，也不发送给生图模型。
8. 新结果同时保存干净母图、带可见水印图及两组切片，前端提供带/无水印切换。只是平台自有可见水印，不处理模型或文件中其他AI标识。旧结果没有干净版本时不显示切换，不伪造去水印。
9. PE备份使用独立Markdown文件，备份工具禁止覆盖。运行提示词、模板、关键约束源码及SHA256均可审查。

## 输出规格与当前产品入口的区别

已登记9种具体类型与全案默认组合，推荐菜归入菜品单品图。
五连图20:3→5张4:3；三连图12:3→3张4:3，设计完成后裁切。
Logo、套餐主图、代金券主图为4:3画布、1:1核心内容区域，初始坐标按居中配置，装饰不受安全区限制。
首页装修图、详情页的未明确规格保留未配置。

本轮现有一键生图入口仍创建五连图。三连图已验证规划/渲染可复用；没有在UI新增其他图片类型、全案调度或Logo生成入口。单图类型目前仅登记规格，尚无对应已审核模板，因此不会伪装成可用功能。

## 审核边界与后续事项

- 12种模板是可执行区域规则初版，不是12套已达到稿定案例品质的美术母版；需要逐套看样张后再完善。
- 本轮没有复制参考案例原图或未授权图层；模板是原创区域定义，案例拆解尚未全部接入检索。
- 生图模型仍只生成画面，本地文字层在模板指定位置排字；尚未实现AI字体艺术设计或独立文案生成/审核模型。
- 门头识别增强接在已有分析入口，不是每次一键生图都自动增加OCR付费调用；未识别或未确认的信息不会自动补入。
- Logo线索只是资料，不是高保真矢量Logo；环境图是否可直接入画尚待确认，当前仅识别资料。
- 模型视觉质量、真实素材抠图融合、字体美术与逐模板真实样张验收未完成，不能以单元测试替代。
- 旧方案兼容代码保留；新创作使用 region-master-v3。历史任务不重生成、不覆盖、不额外收费。
