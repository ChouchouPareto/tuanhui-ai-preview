# 一键生图 v0.9.1：紧凑布局与照片层叠

日期：2026-09-12。基于 v0.9，仅调整一键生图，不改变专业创作、模型调用或生成授权逻辑。

## 本次变更

- 首页取消垂直居中产生的大段顶部留白，缩小标题、模式入口与输入区域之间的距离；欢迎态输入高度降至 80px。
- 删除指定品牌的占位示例，改为“想做什么图？说一句想法，或添加几张参考照片。”不预填用户输入。
- 上传后照片收在原加号卡片内，最多三层缩略图并显示总张数，不再追加独立缩略图行。
- 鼠标悬停展开浮层，支持继续添加、预览和取消引用；展开不改变页面布局高度。
- 手机点击卡片展开；键盘 Enter 展开、Escape 收起；支持外部点击关闭及减少动态效果设置。
- 删除仍沿用原有逻辑：待上传照片移出本次选择；项目素材仅取消引用，不删除原文件。

## 验证

- TypeScript 检查通过；ESLint 无错误，保留四项既有警告。
- 浏览器 mock 回归覆盖单图、四图三层显示、展开前后输入框尺寸一致、删除、375px 展开边界、键盘收起。
- 同时回归专业创作切换保留输入、生成授权、仅启动一次生成、20 条消息内部滚动与停止生成。
- 测试未调用付费理解或生图服务；不代表真实模型生成质量验收。
