# 项目自动命名 v0.9.4

## v0.9.5：区分创建前后

- 未创建项目：标题显示介绍语“从一个想法，开始门店设计”，不伪装成项目名称。
- 创建后：显示已持久化项目名称，规则为“店名＋店铺＋任务方向＋项目”。
- 命名函数按任务 output_type 映射 five_panel / logo / main_image / full_plan，未知方向不猜测。历史缺失类型按既有五图契约兼容。
- 当前创建接口仍只支持 five_panel；本次不开放其他生成能力，也不按自由文本关键字误标方向。
- 7 项命名测试与前端 TypeScript、浏览器回归通过。

- 一键生图命名格式：`{识别到的店名}店铺五图项目`，如“袁记云饺店铺五图项目”。本次方向为五图，不猜测其他项目方向。
- 未识别时使用“店铺五图项目”，不再创建“未命名门店项目”。
- 整理需求成功后，在同一事务保存项目名称；返回 project_name，同步首页标题与左侧历史。
- 仅替换默认名称、当前识别店名、上次快照对应的自动名称。其他自定义名称保持不变。
- 不增加模型调用，也不因命名额外询问用户。
- 已将本地 7 个旧默认项目按最近的一键生图快照更新；无店名则使用中性默认名，未更改素材或生成任务。
- 12 项命名与创作测试、前端 TypeScript 检查通过。
