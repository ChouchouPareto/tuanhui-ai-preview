# 项目自动命名 v0.9.4

- 一键生图命名格式：`{识别到的店名}店铺五图项目`，如“袁记云饺店铺五图项目”。本次方向为五图，不猜测其他项目方向。
- 未识别时使用“店铺五图项目”，不再创建“未命名门店项目”。
- 整理需求成功后，在同一事务保存项目名称；返回 project_name，同步首页标题与左侧历史。

- 不增加模型调用，也不因命名额外询问用户。
- 已将本地 7 个旧默认项目按最近的一键生图快照更新；无店名则使用中性默认名，未更改素材或生成任务。
