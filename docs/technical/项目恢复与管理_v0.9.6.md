# 项目恢复与管理 v0.9.6

## 恢复修复

- 项目列表结果链接使用 task，而新版创作恢复此前仅读 creation，导致原结果未被呈现。
- task 查询增加归属 creation_id；恢复支持 project、task、creation 三种入口，旧任务无 creation 时直接展示已保存结果。
- 有项目恢复时打开消息区域，避免结果和错误被欢迎态隐藏；compose=1 保持新建创作，不自动恢复旧任务。
- 创作历史直接进入当前项目，不再一律跳到全部项目。
- 已对真实保存的山西面馆作品执行只读浏览器验收：三种链接、刷新、返回项目再进入，图片解码成功，未调用生图。

## 项目菜单

- 卡片右上角 ⋯：编辑名称、复制、隐藏、删除。
- 隐藏从默认列表移出，可在“已隐藏”取消；删除二次确认后进入回收站，可恢复，不物理删除文件。
- 有未完成任务时禁止删除，提示先停止任务。
- 复制新项目、独立素材记录和品牌资料，不复制历史生成任务，不触发模型。原始素材文件引用复用，目前仅软删除，源文件不清理。
- 手动修改项目名称后，自动命名不再覆盖。
- 新增 project_display_states 表，沿用当前本地 create_all 建表方式，不改变原项目表数据。
- 本次未删除、隐藏或复制用户真实项目，管理写操作在隔离测试库验收。
