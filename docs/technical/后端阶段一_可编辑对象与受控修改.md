# 后端阶段一：可编辑对象与受控修改

2026-09-16；关联 R02/R04/R05/R06/R08/R09/R15。状态：本阶段 API 已实现并离线验证；未接正式前端/语义 Agent，不等于完整后端完成。

## 本阶段合同

- 画布：明确输出类型、尺寸和裁片数；五连图 4000×600、三连图 2400×600、单项 800×600。全案由多个画布组成，不是单个特殊比例。
- 对象：稳定 ID、类型、角色、文本/素材绑定、归一化位置、字号/颜色、层级、锁定/可见；输入拒绝未知字段、重复 ID、非有限坐标及越界。
- 版本：不可变快照、父版本、内容 hash；写入使用基版本与幂等键，过期写入拒绝。恢复创建新版本，历史不覆盖。
- 查询：可按选中 ID、原文、角色及裁片区域查找；约束取交集，不匹配则询问，绝不退化为改所有标题。
- 修改：对象明确且动作支持才生成提案；应用时重新校验基版本、锁定、容量和未修改对象。不能生成图片作为本地编辑的兜底。
- 资产：只读登记素材；门头/菜单不得绑定成品图片层。原生生成保留无字排字底层、文字对象、来源指纹。历史没有结构时拒绝猜造。
- 导出：新版本独立输出带/不带水印母版与 4:3 裁片，来源标记不因无水印删除；检查文字重叠、溢出、裁切安全区。

## 关键接口方向

前缀 `/api/v1/projects/{project}/canvases`：

| 方法与路径 | 行为 |
| --- | --- |
| `POST /`、`GET /` | 创建原生画布、列举项目画布 |
| `POST /import` | 以已成功单项 `task_id` 导入原生场景；全案指定子任务 |
| `GET /{doc}`、`GET /{doc}/versions`、`GET /{doc}/versions/{version}` | 当前版本、历史、指定旧版本 |
| `POST /{doc}/mutations` | `base_version_id + request_key + operations`，受控新版本 |
| `POST /{doc}/restore` | 指定历史内容追加恢复版 |
| `POST /{doc}/versions/{version}/fork` | 复制历史为独立画布，不改变原画布 |
| `POST /{doc}/resolve-edit` | 返回原文候选或绑定版本的提案，不修改作品 |
| `POST /{doc}/proposals/{id}/apply` | 再校验后应用明确提案 |
| `GET /{doc}/versions/{version}/assets/{filename}` | `long.png` / `01.png` 等；默认预览，`download=true` 才下载 |
| `POST /{doc}/versions/{version}/export` | 原生母版与 4:3 裁片 ZIP；`watermark=false` 可无水印 |

`GET /api/v1/editor/contracts` 返回机器可读 Schema 和真实能力边界。这里的提案/应用两阶段是后端安全合同，不要求未来 UI 对每次明确且无额外付费的改字增加二次确认。

原生成任务的原生场景通过 import 接入，不改旧任务成功状态。版本另存冻结的 `clean.png` / `marked.png`，导出不再用当时最新字体重画旧版本。反复创建/导入会产生独立画布；当前幂等保证覆盖修改/恢复/提案应用，尚未覆盖重复创建。

错误区分不存在、项目不匹配、版本过期、幂等冲突、对象锁定、歧义、文字容量、缺失原始结构和文件指纹变化；返回可操作说明，不暴露路径/堆栈。

## 测试和验收

- 主/副标题、重复原文、选择与语义冲突、跨版本/项目、空目标；歧义不写新版本。
- 更新一段文字时，其他对象结构完全相同；超长文字和碰撞被拒绝。
- 双击/重试返回同结果；不同内容复用幂等键拒绝；并发旧版本不能覆盖新版本。
- 锁定、恢复、重开、裁片映射；价格/Logo/套餐核心 1:1 安全区。
- 原生生成 → 保存对象/无字底层 → 导入 → 修改 → 导出 → 下载，实际 Pillow 文件验收；禁止调用模型的断言覆盖本地编辑路径。
- 临时测试库与独立目录，不改用户作品。后续真实模型对照不以模拟调用替代。

## 边界

本阶段不把旧平面图片重建成完美图层，不开发前端交互。缺乏真实视觉/字体/模型证据时明确待验；API 能力不等于最终产品体验验收。

图片对象目前复用现有 `product + dish/signature_dish` 成品白名单；其他行业的商品/Logo 资产语义白名单尚需扩展，不能把所有引用资产默认放行。字形不是任意字体上传，当前沿用项目内的本地字体选择；提供字号、颜色与测量后换行结果。
