# 前台创作与内部后台拆分

对应需求：R01、R06、R12、R14、R15、R16、R17。用户确认内部产品后台，与 R18 待确认的商家经营后台不是同一需求。

## 入口与职责

| 入口 | 职责 | 边界 |
| --- | --- | --- |
| 前台 3011 `/` | 现有首页、项目与历史兼容 | 保留旧结果 URL；新版创作链接带项目和当前任务 |
| 前台 3011 `/create?entry=oneclick` | 一键单项创作 | 共用受控 Agent、方案确认、计时与作品预览 |
| 前台 3011 `/create?entry=professional` | 专业创作功能入口 | 可进入 `/editor`，不是正式无限画布设计 |
| 前台 3011 `/create?entry=fullplan` | 全案组合交付 | 保留默认券/五图/Logo，费用按方案确认 |
| 前台 3011 `/editor?project=…` | 结构编辑、版本、导出 | 复用本地编辑接口，不调用图片模型 |
| 内部 3021 `/workbench` | 管理导航、只读模型状态 | 不显示商家创作表单；不是经营后台 |
| 内部 3021 `/workbench/templates` | 模板坐标与审核记录 | 审核记录仍非发布门禁，新方案未实施 |

旧 `/workbench/editor` 链接保留重定向，并保留 project/task。创作记录使用原数据库与接口，不复制、不删除用户项目。旧正式页的全部交互尚未被新简洁功能页替换，正式视觉整合仍需 Figma 审核。

## 管理访问保护

- 前台进程 `TUANHUI_ADMIN_ENABLED=0`；管理路由默认关闭。
- 独立后台进程启用管理入口，HTTP Basic 用户名 `admin`，密码为本机生成的至少 32 字符随机凭据。仅监听 127.0.0.1；非 localhost 部署必须先加 HTTPS 和正式账号体系。
- 后台 `/api/internal/*` 仅允许模型合同读取、模板读取及审核三个具体路径，不是任意 API 代理；POST 必须同源。
- 管理 API `/templates/reviews`、`/templates/{id}/review`、`/agent/contracts` 独立校验 Bearer。绕过页面直接访问也被拒绝。
- 凭据不使用 NEXT_PUBLIC 变量，不返回给组件，不提交 Git。无管理员配置时返回不可用，而不是放行。
- 此为本地单管理员门禁；没有多用户角色、SSO、生产限流、用户归属检查或完整审计。公共项目/素材 API 仍是单用户原型，禁止据此开放互联网收费。

## 启动与凭据

项目根目录运行 `.venv/bin/python scripts/start_local.py`。默认 API 8011、前台 3011、后台 3021，可用三个端口参数分别配置。端口冲突直接退出，不自动杀进程。

首次启动自动建立 `runtime_logs/local-admin.key`，权限 0600，不在终端输出密码。内部后台登录时，用户名 `admin`，密码由本机用户打开该文件读取。不要把文件提交、截图或发送给商家。前后台共享业务存储，一次构建后以两个独立进程/端口运行；不要同时启动两个 Next 开发进程，避免自动改写同一个 TypeScript 配置。代码更新后重新运行启动脚本构建，不使用双端开发热更新。

## 本轮验证

- 后端全量 282 项通过，包含未配置拒绝、错误身份拒绝、直接管理 API 防绕过与原模板 hash 过期校验。
- 前端 23 项通过；类型检查及本轮文件 lint 通过。
- 隔离数据库、真实 API 和 Chrome 检查：零调用整理方案、投诉、创建画板、本地文字修改、工作区保存、390px 窄屏；前台模板入口关闭、后台未授权拒绝、已授权模型配置/模板页面可读取、跨站 POST 拒绝、任意代理路径拒绝。
- 本轮没有调用付费模型，没有变更 PE/模板内容，没有推送 GitHub。
- 本地服务已切换到 3011 前台、3021 后台、8011 API。实际 HTTP 核对前台 200、前台后台路径 503、独立后台未登录 401/登录后 200、后端管理接口未登录 401。原 18 个项目、49 条任务、12 份素材数量保留；本轮浏览器写入均使用隔离测试数据库。
- 启动过程中发现双 Next 开发进程并发改写 tsconfig 导致短暂 500；已修复为一次构建后独立运行，并通过真实端口检查。构建完成不等于用户视觉验收。

## 不包含
