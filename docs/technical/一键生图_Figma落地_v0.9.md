# 一键生图 Figma 落地 v0.9

日期：2026-09-12
分支：feature/oneclick-figma-v0.9
基线：feature/m1-chat-creation-v0.7；设计：Figma cdZ0ElWdGC5yT11lkbNFLg。

## 本轮实际实现

1. 新首页只沿用「创作 / 一键生图 / 全案设计」切换入口；其余采用 Figma 的简洁输入、独立聊天工作区和固定底栏结构。
2. 添加照片改为输入框内的倾斜卡片；悬停仅 transform 放大，不改变容器高度；支持 reduced-motion、键盘操作。
3. 上传缩略图复用原预览组件；悬停预览不会挡删除，点击可放大，删除只移除本次引用。
4. 原左右素材区、需求输入、模型/风格/模板工具栏保留在专业创作；首页模式切换保持当前输入。
5. 桌面/手机消息区独立滚动，修复自动聚焦时 scrollIntoView 推动整个页面的问题；输入区不随聊天条数增长。
6. 一键生图首次发送前显示本地内测费用授权；没有伪造 Figma 的 10 积分报价。授权后，本轮整理完成且 ready 即提交该 snapshot 的 confirm，不再等待第二个生成按钮。
7. 无可渲染素材时，客户端显式传 allow_illustration，允许有品牌/主题的需求走带标识示意图；真实菜品优先，用户明确只用实拍仍保留约束。旧客户端和专业模式门槛不变。
8. 保留 revision、snapshot_hash、幂等键和服务端素材使用权校验；失败不自动重试。
9. 工作区展示实际任务进度、停止状态、长图和切片下载；继续创作与返回项目仍可使用。
10. 本地服务：前端 3011，后端 8011；确认没有在途任务后重启后端加载新策略。

## 尚未实现，不能宣称完成

- Figma 的区域图像编辑、版本对比 UI 和纯排版编辑服务；当前对话修改不等于局部编辑。
- 正式积分报价、余额校验、订阅扣费和赔付。
- 更换对话模型及完整 Agent 动作协议；现有五字段理解与规则回复仍在，不能宣称已升级为自然对话 Agent。
- 自动视觉分类：当前“加照片”按菜品上传；门头需从「素材与设置 → 添加门头参考」上传。不得把此实现称为自动识别素材用途。
- 全案设计保留不可用入口，本轮没有实现该业务。
- 未发布 GitHub Pages，未修改密钥配置。

本轮是首页/聊天布局与提交衔接版本，不是全部 Figma 演示能力的上线完成记录。
