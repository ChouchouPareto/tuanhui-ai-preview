## 已实现

1. 一键生图首页可先提交文字，再在同页集中补齐真实菜品与展示信息。确认卡紧接输入框，未识别字段可手动填写。
2. 不展示价格则不要求价格；不展示店名则不要求展示名称；不强制上传门头。门头、菜单仅识别，不能替代真实菜品图。
3. 每次创作有独立 ID、递增修订、来源标记、素材清单和哈希。确认前重新验证素材归属、分类与文件内容。
4. 已确认的项目资料可作为本次输入；本次更改不自动覆盖项目长期记忆。
5. 最终确认冻结快照；重复确认复用任务，旧修订不能覆盖新修订。修改确认卡后必须保存才能生图。
6. 生成队列与任务同事务保存，独立 Worker 执行。关闭页面不取消已确认任务；刷新通过 creation URL 恢复资料和任务。
7. 新流程最多提交所选一个模型，不自动切换备用模型；执行中断或结果未知进入待核对状态，不自动重试付费请求。
8. 复用既有五图母版、确定性排版裁切服务，只传入本次确认的可渲染素材。产物可下载，可继续下一次创作，旧作品保留。
9. 提供暂停后续处理入口；明确供应商已收到的请求不保证取消、不保证免计费。
10. 测试数据库和测试上传目录改为独立临时目录，避免测试清理真实素材。

UI 本轮使用 ui-ux-pro-max 的集中错误提示、字段关联错误与可见焦点规则；保持原首次成型版视觉与专业创作入口。

## 与技术设计的差异及尚未完成项

| 项目 | 当前实现 | 后续门槛 |
|---|---|---|
| 需求理解 | 规则识别带标签文本＋手动确认；use_ai=true 明确拒绝 | 接入有预算授权的 AI 理解、图片语义核验，并做真实案例验收 |
| intake-runs | 同步返回 200，无理解模型任务 | 如引入慢模型，改为持久任务＋202／轮询 |
| 专业创作 | 保留原事实与设计方案确认交互；取消后端强制门头，支持价格条件规则 | 尚未完整迁移到新 Creation／统一补问契约，不宣称双入口全面统一 |
| 恢复 | 原始需求在确认卡可查看；事实字段和任务通过 URL 恢复 | 首页主输入框未自动回填；完整跨设备草稿列表待开发 |
| Worker | DB 队列、租约、心跳与未知结果保护 | 非完整断点续跑；需供应商结果对账与人工处置 UI |
| 费用 | 生成前明确模型费用并要求勾选授权 | 尚无金额报价、预算上限、积分账本或成本测算 |
| 权限 | 项目归属校验 | 没有正式多用户认证授权；不得直接开放为生产服务 |
| 生成质量 | 复用母版实现；自动化不等于美术验收 | 本轮未真实付费生图，效果与成本需专项测试 |

未开发：装修全案、Logo 单独生成入口、局部重绘、订阅积分、两小时人工服务与自动赔付、正式云部署。这是 M1 第一段可测试切片，不是完整 M1 验收通过。

## API 契约摘要

- POST /api/v1/projects/{project}/creations：新建本次创作，201。
- POST .../creations/{creation}/intake-runs：expected_revision、text、asset_ids、answers、展示开关及风格模型；必须提供 Idempotency-Key。同步 200。
- GET .../creations/{creation}/review：当前快照、revision、snapshot_hash、task_id、execution_state。
- POST .../creations/{creation}/confirm：revision、hash、素材确认与 local-paid-generation-v1 费用授权；事务创建方案、任务和确认记录。
- GET /api/v1/tasks/{task}：查询生成状态；POST /tasks/{task}/pause：暂停后续处理。
- 错误通过 HTTP detail.code/message 返回。冲突通常 409；同键不同正文不得当作成功的新提交。

## 本地启动与测试

以下前三个命令均从仓库根目录执行；环境变量沿用本地配置，不向前端暴露密钥：

```sh
.venv/bin/python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8011
PYTHONPATH=backend .venv/bin/python -m app.worker
.venv/bin/python -m pytest backend/tests -q
```

另开终端进入 frontend：

```sh
NEXT_PUBLIC_API_BASE=http://127.0.0.1:8011/api/v1 npm run dev -- --hostname 127.0.0.1 --port 3011
npm run typecheck
npm run lint
npm run build
```

不要让 dev 和 build 同时写同一 .next 目录。GitHub Pages 的静态预览不等同于本地后端＋Worker 的可生成版本。
