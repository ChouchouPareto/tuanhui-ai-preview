# 一键生图 v0.9.3

## 故障原因与修复

本地 API 已运行，但没有运行 `app.worker`。确认接口只创建持久化队列记录，不直接执行生图，导致任务停留 PENDING。前端此前将 PENDING 与 RUNNING 都显示为“正在生成”。

- 已启动独立 worker，并在 README 写明从同一仓库根目录启动 API、worker、前端的方法。
- 新增数据库 heartbeat 表 `generation_worker_heartbeats`，启动时沿用现有 create_all 建表。worker 每 10 秒更新，45 秒内有效。
- 新确认检测不到 worker 时返回 503 / WORKER_UNAVAILABLE，保留 READY_TO_CONFIRM，不创建任务、不调用生图模型。此保护不代表之前的文字理解免费。
- 排队阶段明确显示“尚未开始生图”；运行阶段才显示正在生成。
- 保留原有任务幂等领取、停止、异常核对逻辑；未恢复已停止任务、未重试未知结果。
- `/health` 增加 generation_worker_ready。worker 启动后本地返回 true。
- 运行中突然掉线仍依赖既有租约恢复，不能将 heartbeat 判断当作绝对执行保证。

## UI

- 全局应用链接不再使用浏览器默认蓝色和下划线；主按钮维持白字，返回项目采用轻边框按钮，保留键盘焦点。
- 照片入口参考 [Glass Icons](https://reactbits.dev/components/glass-icons) 的半透明前后叠层及悬停错位。
- 展开参考 [Bounce Cards](https://reactbits.dev/components/bounce-cards?enableHover=true) 的卡片散开效果，适配成向上弧形、半透明背景。采用本地 CSS 动画实现，不运行 shadcn 安装命令，不引入 GSAP 或覆盖现有组件。
- 每组最多 5 张，超过可翻组；支持预览、细线删除、移出收起、触屏与键盘操作、减少动态效果设置。
- 样式只改一键生图照片组件，专业创作照片区保持原样；链接规范为全局修复。

## 验收

- 后端 70 项测试通过（包含 mock worker 成功执行一次、幂等、停止及离线不入队）。
- 前端生产构建与浏览器回归通过：悬停收起、375px 扇形边界、布局高度不变、链接无默认蓝色/下划线、生成与停止流程。
- 验收未发起真实付费生图。当前历史任务已停止，仍保持停止；用户下一次主动生成后才能确认真实模型端到端结果。
