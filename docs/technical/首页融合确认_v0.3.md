# 首页融合确认 V0.3

日期：2026-09-08。范围：按用户确认的“删除不必要项、融合到原 UI”方案优化一键生图；不改变专业创作原流程。

## 交付

- 将大表单改为接在首页输入框底部的轻量确认区，移除 M1 标题、原始需求折叠区和主界面技术说明。
- 已知店名／菜品显示摘要，点击即可编辑；缺少信息直接输入；价格仅开启展示后出现。
- 特色和卖点合为一个选填入口，默认折叠；内部仍提交兼容的事实字段。
- 删除确认区重复的模型、风格控件和素材文件名列表。模型风格使用首页当前值；已存快照刷新时回填首页。
- 本次素材沿用原门店／菜品框：取消引用不删除项目素材，素材管理提供“重新选入项目素材”入口。
- 原始需求刷新回填；原首页箭头在确认区已存在时定位到确认区，不重复发起整理覆盖编辑。
- 一次“确认并生成”串行完成待上传素材保存、输入保存、校验、冻结确认与任务提交。保留费用/素材授权；修改输入、参数或引用后授权失效。
- 确认响应丢失后先查当前状态，已确认直接复用；未完整资料及保存失败不进入生成；原有服务端幂等保护不变。

## 验证

- 后端原有 35 项测试通过。
- 新增前端 5 项离线流程测试：保存先于确认、缺失不生图、保存失败不生图、确认响应恢复、确认失败不自动重试。命令：frontend 中 npm run test:confirmation（Node 24）。
- TypeScript 与 ESLint 无错误，保留 3 项既有警告；Next 生产构建通过。
- 浏览器验证已知字段摘要、价格开关、375px 单列布局、原箭头定位确认区；未发起真实付费生图。
- 真实模型效果、完整素材上传到生图链路和跨设备草稿仍需后续专项验收。本轮未接入 AI 理解、计费报价，也未推送或部署。
