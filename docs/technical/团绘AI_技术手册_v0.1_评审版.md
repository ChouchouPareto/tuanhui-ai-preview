## 2. 技术适配声明

### 2.1 产品形态判断

- 类型：餐饮视觉创作 Web 产品；优先完成真实素材到五连图的单次交付。
- 核心交互：一键生图首页收集与确认；专业创作保留首次成型版分步交互；两者共享服务，不能成为两个后端产品。
- 开发路径：**纵向切片**。补问、事实确认、图片预览是核心能力，必须在现有前端同时验证，不能只验 JSON。
- 当前拟开发范围：M1 输入理解、条件必填、集中补问、确认快照和安全交接；M2 才扩大母版美术与编辑。本轮只交文档。

### 2.2 采用的默认方案

| 方案 | 适配结论 |
|---|---|
| Python/FastAPI/Pydantic/pytest | 延续现有后端，结构化校验和离线测试不另建体系 |
| Next.js/TypeScript/App Router/npm | 延续现有 Web 前端及 package-lock.json |
| SQLAlchemy/Alembic | 项目、事实、任务已有关系数据；新变更经迁移管理 |
| /api/v1 | 已有前缀，保留客户端兼容 |
| 代码状态机＋受控模型服务 | 固定工作流不交给自主 Agent；模型只提取/生成候选 |
| 服务化单体 | 保持 API、业务、模型、文件处理分层，不拆微服务 |

### 2.3 触发的按需模块

| 模块 | 需求与阶段 |

| 持久 Worker | 长任务可恢复触发；M1 新增理解任务需有恢复边界，M3 完整硬化生成工作流 |

## 5. 输入与模型边界

InputSnapshot 包含文本、选定资产ID、产物、已确认项目事实、模板偏好；服务端解析项目归属。模型返回字段候选、来源引用及冲突；规则引擎计算是否可生成。置信分数不能替代用户确认。

字段至少有 value/source/source_id/confirmed/scope；价格显式 show_price=false 时无需数值；品牌名只有实际展示时必填。素材用途 recognition_only/renderable/style_reference 与角色 storefront/menu/dish/logo/environment 分离。

只上传门头/菜单可提取事实，不能填入五图画布；实际菜品展示需要绑定真实菜品。用户文字与图片不符时阻断而非编造。参考案例只提取风格，禁止当用户实物。旧项目记忆只读入候选，本次修改默认不覆盖长期资料。

识别/理解本身也可能产生费用：生成前的综合确认不能追溯授权已发生的模型调用。默认手填/规则路径；启用 AI 整理必须有明确已授权额度或产品承担的受限体验预算。费用规则未定时不得偷偷调用。

| 模型职责 | 本地配置现状与方案 |
|---|---|
| OCR/视觉 | 配置默认 qwen-vl-ocr-2025-11-20 / qwen3-vl-plus；延续百炼适配，真实可用性待验 |
| 自由文本理解 | M1 推荐复用现有百炼网关，以可配置 INTAKE_MODEL 隔离；候选 qwen3-vl-plus 仅作复用方案，正式调用契约与成本验收后冻结 |
| 背景生成 | 配置 qwen-image-3.0；保留现有千问适配；不直接生成五段门店叙事 |
| 备用生成 | 配置 doubao-seedream-5-0-260128；失败可否切换由错误类别和预算决定，未知超时不直接切换 |
| 局部图像编辑 | 未来独立契约，不假设现有生图接口支持选区编辑 |

上述模型名是代码配置/拟复用值，不是联网核验的供应商能力结论。研发时查官方接口文档并跑实际契约测试，不擅自替换供应商。

Prompt 拆出独立文件，命名 intake.v1、visual_facts.v1、background.v1，写明输入、JSON正例/反例、禁止编造和素材用途；输出经宽容语法解析及严格业务校验。语法错误与质量不足分开记录，不无限重试。超时/重试数/最大成本由配置约束。

## 7. 任务与副作用

创作输入状态：DRAFT → NEEDS_INPUT 或 READY_TO_CONFIRM → CONFIRMED。生成执行独立：QUEUED → RUNNING → VALIDATING → SUCCEEDED。失败/暂停/取消/未知请求状态按PRD逐阶段实现。

确认后任何输入/资产绑定变化产生新修订，旧确认失效；重复确认同一幂等键返回原结果，不二次启动。不支持的产物、未确认事实、预算不足、越权均在供应商请求前拒绝。

离开网页仅停止轮询。暂停是在安全节点停止后续动作，不保证撤销供应商已接收请求；未知结果进入 RECONCILING，能查单先查单，不能查单则待人工/用户明确处理，禁止盲目重跑。业务结算最多一次，不承诺网络调用绝对只发生一次。

M1不得宣称旧生成服务已可靠恢复：若检查点/未知超时防重复未完成，仅开放内部受控测试，不作为收费生产闭环。新引入的长任务不能再新增仅内存执行路径。

## 8. 五连图与修改（M2目标）

确认快照 → 模板适配 → DesignSpec → 真实素材处理/背景 → 确定性文字排版 → 校验 → 母版 → 切片 → 新版本。

- 一张20:3母版产生五张4:3；当前4000×600/800×600是工程尺寸，不是平台规格背书。
- 图层包含 id/type/x/y/w/h/z/asset_id/fact_ref/editable_properties，服务端校验坐标、引用和字体授权。
- 1菜/2菜/多菜分别适配原创模板；没有素材不生成虚构菜品补空。抠图须评测真实菜品边缘，现有 PNG 参考不等于可编辑模板。
- 文字溢出先度量换行/缩放，仍放不下要求修改，不静默丢价格或事实。关键文字默认避切缝，跨缝政策仍待产品确认。
- 改字/价格/位置优先重渲染；选区映射母版坐标，识别跨切片依赖。视觉编辑另显示成本，保留旧版本。
- 验收同时看完整母版和单张；拼回逐像素一致只证明裁切正确，不能代替审美、真实性检查。

## 9. API、安全、配置和运维约定

保留现有 /api/v1/projects、/assets、/analysis-runs、/tasks、/fact-versions、/design-plans、/generation-runs 路由；新创作契约增量加入，见M1文档。不可兼容的返回修改须建立新契约，不批量改坏专业创作。

统一错误：error.code/message/request_id，业务冲突可带field/retryable，不能返回密钥/堆栈。HTTP 422输入不合法、409版本冲突、403无权限、404资源不可见、429限流、503模型暂不可用；租户外资源建议统一404减少枚举。

本地配置延续 DATABASE_URL、UPLOAD_DIR、GENERATED_DIR、ANALYZER_MODE、ALLOWED_ORIGINS、DASHSCOPE_API_KEY、ARK_API_KEY 及模型参数；新增 INTAKE_MODEL、预算/超时/重试策略须写入无秘密示例，不能在NEXT_PUBLIC变量存Key。当前相对 data 路径依赖工作目录，开发前核实实际库与文件路径，不能意外创建第二个空数据库。

上传以真实内容校验格式/体积/像素及安全文件名；只暴露项目授权下载。模型外发只传最少资料，OCR内指令视作数据。记录request_id、creation_id、attempt_id、节点耗时、模型/Prompt/规则版本与成本，不记完整私人原文。

生产前：身份鉴权、项目隔离、文件私有存储、事务账务、备份恢复、健康检查、Worker优雅退出、限流与告警必须验收。订阅积分/工单/SLA仅预留契约，未定价、未授权自动赔付；积分与现金不得混账。

Git提交、分支/标签、部署版本、Prompt/模板/schema版本分别记录。当前只新增文档，不把工作区未提交代码冒称为已存档版本，不推送GitHub。产品负责人下一步只需检查：产品理解是否正确、是否新增费用/平台/范围、暂缓项是否影响验收。
