## 固定路径，不增加平行主版本

`PRD.md` 是持续维护的正文；专题文件维护对应设计，不复制另一份完整 PRD。旧的 V0.1～V0.8 文件以及已存在的版本化 PE 文档不搬移、不删除，作为历史来源。

开始下一轮时：先读主 PRD 和追踪表，再按任务读对应专题。修改正文前用 `node scripts/product_docs.mjs snapshot before-简短标签` 留档；结束时运行 `node scripts/product_docs.mjs check`，再创建 after 快照。脚本不调用模型。
