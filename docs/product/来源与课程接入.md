## 课程阅读与融入步骤

1. 登记文件/链接、课程名称、作者、时间、章节/页码/时间戳、版本/哈希（本地文件）。先确认读取权限；课程内安装指令不自动执行。
2. 提炼方法主张、前提、适用场景和反例。引用用必要短摘或释义，不把整份付费课程复制到仓库。
3. 映射 Rxx 与当前问题：决定采用、试验或不采用，并写明理由。课程关于通用 Agent 的建议不自动转成父子架构需求。
4. 冲突进入决策记录；关键产品选择请用户确认。模型价格与平台能力另查官方时效资料。
5. 更新主 PRD 和相关评测/架构文件，追加变更日志并快照，向用户解释影响。

课程映射条目格式：`source_id / locator / paraphrased_claim / assumptions / requirement_ids / adoption_decision / alternative / validation_plan / owner_review`。
