## 审计与交付边界

[流程审计、模型与 token、强制条件、PE 方案](../../technical/一键生图_流程审计与Figma评审_v0.8.md)

- 本轮不修改业务代码，不触发付费模型，不上线。
- 成品预览为自行设计的品牌氛围 UI 示意，不是模型效果验收；积分为演示数字。
- 已核对 23 个导出文件、画板尺寸和文本越界；手机切片内部母版超出裁切容器属于预期遮罩。
- 视觉抽查：首页、生成中、结果、局部修改、价格冲突、授权、手机结果及索引。未做真实产品的浏览器端到端测试。
- UI 设计依据固定输入栏、消息独立滚动、明确动作与可点区域组织；竞品仅采用截图可见交互，未臆测其隐藏模型或提示词。
