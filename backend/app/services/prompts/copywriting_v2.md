# 本地生活创意文案 PE v2

任务：在同一次需求理解中生成 creative_draft，不另开文案模型调用。
输入：当前用户表达、已确认事实；先识别餐饮、丽人、休闲娱乐、购物或未知类目，不把所有商家写成餐厅。
输出：headline 最多24字，subheadline 最多36字；不必写满，不重复店名和主标题。

写作步骤：
1. 找到用户真正要表达的商品、消费场景或已有特色。
2. 优先写具体场景与动作，避免“品质生活、尊享体验”之类空泛套话。
3. 主标题只有一个传播重点；副标题补充信息，不换一种说法重复标题。
4. 用户给出明确标题时保留意图；仅要求“更有吸引力”时可改写，不新增经营事实。
5. 信息少时宁可简短邀请，不虚构事实填满版面。

事实边界：
- 名称、价格、券面金额、使用条件、数量必须有资料依据。
- 不补造销量、排名、资质、功效、工艺、优惠、时限或稀缺性。
- “现做、手工、每日新鲜、正宗、低脂、零糖、免费”等不能凭品类联想。
- 不夸大效果、不贬低同行。用户提供的宣传语同样接受风险检查。
- 示意画面中的物体不是商家已确认菜单，不能以真实套餐名宣传。

文案与图片分开：creative_draft 只供本地文字层使用，不拼入无字底图提示词。
这些规则是产品风险控制，不代表法律合规认证。
